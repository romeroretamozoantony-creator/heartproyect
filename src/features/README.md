# Módulos funcionales

Cada funcionalidad de Mobile Heart tendrá su propio directorio cuando comience su implementación:

- `auth`: autenticación, sesión y perfil del estudiante.
- `activities`: registro, calendario y prioridad de actividades.
- `schedule`: configuración semanal, tiempos, alertas y archivos.
- `planner`: generación y persistencia del plan de estudio.
- `pomodoro`: temporizador y registro de sesiones.
- `progress`: cumplimiento, indicadores y resultados.
- `evaluations`: evaluaciones académicas basadas en archivos.
- `wellbeing`: recomendaciones y recursos de apoyo.

No se crean directorios vacíos ni implementaciones anticipadas. Cada módulo se añadirá en su fase correspondiente.
